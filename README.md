# Physics Engine

A standalone desktop physics simulation built with HTML5 and Electron.

## How to Install & Play (Windows)

### Option 1: Using the Installer (`Setup.exe`)
1. Download **`my-html-app Setup 1.0.0.exe`** (or **`Physics Engine Setup.exe`**).
2. Double-click the `.exe` file to run it.
   * *Note: Because this is an indie app without a paid Microsoft certificate, Windows Defender SmartScreen may show a **"Windows protected your PC"** popup. Click **More info** and then click **Run anyway**.*
3. The installer will automatically set up the game in the background and launch it when finished.
4. You can launch the game anytime later from your **Windows Start Menu** or **Desktop shortcut**.

### Option 2: Portable Version (No Installation Required)
1. If you downloaded the **Portable `.exe`** or the zipped **`win-unpacked`** folder, extract the `.zip` file anywhere on your computer (such as your Desktop or Documents folder).
2. Open the folder and double-click **`my-html-app.exe`** (or **`Physics Engine.exe`**) to start playing immediately.

## System Requirements
* **OS:** Windows 10 or Windows 11 (64-bit)
* **Storage:** ~250 MB of free disk space

## Troubleshooting
* **Blank or white screen on launch:** Make sure you extracted all files from the `.zip` archive before running the `.exe` (do not run it directly from inside the compressed `.zip` folder).
* **Antivirus warning:** If your antivirus blocks the file, add an exception for the game folder. Electron apps packaged by independent developers are occasionally flagged as false positives.
